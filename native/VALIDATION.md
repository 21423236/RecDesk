- 无声桌面录制、系统声音录制、系统声音 + 默认麦克风混音均成功输出 H.264 / AAC MP4。

- 播放测试正弦音并录制 WASAPI 系统声音，输出的音频 RMS 约 -36.3 dB，确认不是仅创建了一条静音音轨。
- 90 秒真实桌面录制：源显示器 3840×2160，输出 1920×1080，设置 30 FPS，启用系统声音和麦克风。
- 输出 MP4 时长约 90.37 秒、大小 16,006,644 字节；视频 H.264、音频 AAC；FFmpeg 完整解码无错误。
- 10–81 秒采样：控制测试进程私有内存约 3.7 MiB，FFmpeg 私有内存约 169–169.2 MiB，未观察到随录制时长持续增长。
- 该测试输出 2546 帧，平均约 28.2 FPS，**观察到掉帧**。当前 GDI / CPU 编码后端不能据此宣称 4K 输入、30 / 60 FPS 均可满帧运行。

- 强制终止录制控制进程，确认编码子进程随 Job Object 退出、MKV 和恢复信息仍存在；随后成功恢复约 5 秒 MP4，完整解码无错误。
- 2 秒 VP8 / Opus 旧版 WebM 成功转为 H.264 / AAC MP4。

## 讲话时爆音的音频处理修复（2026-11-03）

- 修正逐包 `ceil` 起止时间造成的边界重叠。相同的 60 秒 / 48 kHz 合成包序列中，旧计算复现 626 处重叠；新处理输出 2,880,000 个唯一连续采样帧，恒定幅度没有翻倍尖峰或空洞。
- 每路声音使用独立的时间线贡献；重复写同一路采样不再累加，不同来源才做归一化混音。重复设备包直接去重，部分重复前缀截去，真实丢包保留相应静音间隔。
- 16 / 32 / 44.1 / 48 / 96 / 192 kHz、不规则大小音频包的正弦信号测试，与连续插值参考的误差断言通过；44.1 kHz 麦克风与 48 kHz 系统音的 60 秒合成混音无幅度尖峰。
- 两分钟合成时钟测试：±300 ppm 采样时钟偏差叠加 ±0.3 ms 包时间戳抖动后，剩余时间误差约 -31.52 / +30.48 帧（48 kHz 下不足 0.66 ms），波形相邻样本连续性断言通过。零偏差测试为 0 帧误差。
- 覆盖时间戳无效、真实流中断、环形缓冲区回绕、双声道独立性和八小时数值起点。模拟时间不代表进行了真实两分钟或八小时录音。
- Release x64 已重新编译并发布到 `native/release/RecDesk.exe`。CTest 四组 `recdesk_core`、`recdesk_audio`、`recdesk_export`、`recdesk_ui` 全部通过，未跳过。
- 本次测试仅用合成采样，没有访问用户麦克风或录制桌面；用户实际人声是否恢复正常仍需复测。未加入降噪 / 回声消除，也不能修复设备端已经发生的削波失真。
